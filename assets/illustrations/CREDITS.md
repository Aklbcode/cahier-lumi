# Illustrations du Cahier de Lumi

Illustrations **Twemoji v17.0.3**, par **Twitter, Inc. et les autres contributeurs**, distribuées sous [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

- Source précise : [dépôt Twemoji — v17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/svg).
- Licence complète : [LICENSE-GRAPHICS](LICENSE-GRAPHICS).
- 405 dessins SVG d’origine inchangés, regroupés dans `twemoji-bundle.js` pour fonctionner localement et hors connexion. Seul le regroupement a été modifié.
- Le manifeste donne le code Unicode, la taille et l’empreinte de chaque dessin.
- Aucune image, police d’emoji ou ressource de ce lot n’est chargée depuis un serveur tiers pendant le jeu.

La bibliothèque de parsing Twemoji n’est pas embarquée ; le code d’affichage local de Lumi n’est pas dérivé de sa bibliothèque.
