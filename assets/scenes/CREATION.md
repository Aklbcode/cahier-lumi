# Paysages de recherche visuelle

Trois illustrations ont été créées avec l’outil de génération d’images intégré :

- `search-park.png` : parc illustré très détaillé, jeux, serre, étang, pique-nique, pont et nombreux petits objets.
- `search-harbor.png` : port illustré, bateaux, marché, phare, caisses, cordages et petits objets.
- `search-forest.png` : forêt illustrée dense, cabanes, maisons champignons, lanternes, livres, fleurs et ruisseau.

Brief commun : paysage de livre jeunesse, vue large en 3:2, formes lisibles, détails nombreux, aucun texte ni personnage cible intégré dans le fond. Les vrais personnages et leurs zones tactiles sont ajoutés par le code du jeu, dans un repère unique qui reste aligné pendant le zoom.

Fichiers originaux générés conservés dans le dossier local de génération ; copies de livraison ici en PNG 1536 × 1024. Les images de personnages sont des fichiers sources distincts avec leurs propres crédits, pas des créations de l’outil.
