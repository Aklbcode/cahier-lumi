# Borel

Police : **Borel Regular**, de Rosalie Wagner. Copie locale de la version distribuée par le dépôt officiel Google Fonts, téléchargée le 23 octobre 2026.

- Police : https://github.com/google/fonts/blob/main/ofl/borel/Borel-Regular.ttf
- Licence SIL Open Font License 1.1 : `Borel-OFL.txt`
- Présentation et conventions du projet : https://github.com/RosaWagner/Borel/blob/main/README.md

Borel est conçue comme une cursive scolaire française, avec des formes ouvertes et différenciées. Le choix de cette police ne signifie pas qu'il existe un modèle cursif unique imposé dans toutes les écoles belges.

Dans Lumi, Borel affiche les exemples de mots liés et les correspondances de formes attachées. Les guides de geste interactifs sont des chemins vectoriels propres à Lumi, avec départ, corps continu et sortie. Ils ne sont pas des contours de police à remplir. Le script de lecture et les chiffres gardent leur police lisible habituelle.
